# 클라우드 세션 사진 편집 절차

앱의 **Claude로 보내기** 버튼이 연 claude.ai Code 세션이 따르는 절차입니다. 환경 설정은 [STANDALONE_DEPLOYMENT.md](STANDALONE_DEPLOYMENT.md)의 "클라우드 세션에서 쓰기"를 보세요.

## 순서

1. `git checkout handoff/weather-tests` 후 `npm ci`. 링크로 연 세션은 `main`에서 시작할 수 있습니다.
2. 원본 준비
   - 요청에 **사진 ID**가 있으면: `node scripts/fetch-trip-photo.mjs --id <ID> --out source.jpg`. 첨부를 기다리지 않습니다.
   - 요청에 **편집용 원본 ID**가 있으면(아직 기록에 없는 사진): `node scripts/fetch-trip-photo.mjs --source <ID> --out source.jpg`. 5단계 가져오기가 끝나면 `node scripts/fetch-trip-photo.mjs --source <ID> --cleanup`으로 임시 사진을 지웁니다.
   - 둘 다 없으면: 사용자가 첨부한 사진을 원본으로 씁니다. 첨부가 없으면 사진을 첨부해 달라고 요청하고 멈춥니다.
3. 사진 분석: 원본 이미지를 직접 열어 장소, 주요 사물(옷·소품·음식·간판 등), 인물 수와 표정·행동, 빛과 시간대를 짧게 정리합니다. 이 내용으로 **편집 요청**을 그 사진에 맞게 구체화합니다.
   - 예: 컬러 낙서 페인팅이면 칠할 부분을 "왼쪽 사람의 노란 모자, 오른쪽 사람의 쇼핑백"처럼 실제 사물로 지정하고, 손글씨 문구를 표정·행동에 맞게 정합니다.
   - 요청의 금지 사항(얼굴 유지, 사실·개인정보 만들지 않기, UI·워터마크 금지)은 그대로 둡니다. 장소·메모가 "비어 있음"이면 요청에 적힌 대로 처리합니다.
   - 구체화한 최종 프롬프트를 대화에 한 번 보여 줍니다(승인을 기다리지 않음).
4. 힉스필드 MCP로 편집: `media_upload`로 원본을 올리고 `generate_image`(기본 `gpt_image_2_5`, medium, 2k, 약 1크레딧)에 3의 최종 프롬프트를 씁니다. 결과 1장만 만들고, 실패하면 한 번만 다시 시도합니다.
5. 결과를 받아 `result.png`로 저장한 뒤 앱 기록에 넣습니다.
   ```sh
   node scripts/import-edited-photo.mjs --file result.png --date <날짜> \
     --uploader-label "<여행자 A|여행자 B>" --place "<장소>" --caption "<메모>"
   ```
   - 날짜·장소·메모·올리는 사람은 요청문 맨 위 값을 씁니다(비어 있으면 빈 값). 메모 끝에 ` · AI 편집`을 붙이고, 메모가 비어 있으면 `AI 편집`만 씁니다.
   - Cloudflare `429`(code 971)가 나오면 응답의 `Retry-After`만큼 기다렸다가 다시 실행합니다. `7403`은 한 번 다시 실행합니다.
6. 결과 이미지를 대화에 보여 주고, "앱 기록에 추가했어요. 앱을 새로고침하면 보여요"라고 짧게 알립니다.

## 하지 않는 것

- 원본 사진이나 기존 기록을 지우거나 바꾸지 않습니다. 편집본은 새 기록으로 추가합니다.
- 커밋·푸시·배포를 하지 않습니다.
- 토큰이나 비밀 값을 출력하지 않습니다.
