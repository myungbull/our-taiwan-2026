## 먼저 처리할 항목

### P0 — AccuWeather 운영 연결

- `ACCUWEATHER_API_KEY`가 현재 운영 비밀 설정에 없습니다.
- Taipei 시간 `2026-11-08`부터 AccuWeather로 전환하도록 구현돼 있습니다. CWA는 사용하지 않습니다.
- 키를 안전한 Sites secret으로 등록한 뒤 타이베이·예류·스펀·지우펀·우라이·타오위안과 11/18~22 예보를 확인해야 합니다.
- 키가 없을 때는 missing-key 상태와 예보 범위 제한을 솔직하게 유지합니다. 기존 Open-Meteo 캐시 또는 16일 전망이 여행 전체를 커버한다고 말하지 않습니다.
- 2026-10-27 Claude Code 세션: Sites 커넥터가 없어 운영 비밀 존재 여부를 직접 확인하지 못했습니다. 상태는 여전히 "미설정으로 기록됨"이며 실시간 연동은 미검증입니다.
- **확인 필요(추정):** 코드는 `forecasts/v1/daily/15day` 엔드포인트와 `Authorization: Bearer` 헤더를 사용합니다. AccuWeather 무료/체험 플랜은 15일 예보를 허용하지 않을 수 있습니다. 키 등록 후 401/403이면 `switchState: unavailable`로 표시되고 1시간마다 재시도만 합니다(테스트로 확인). 플랜 범위를 키 발급 화면에서 확인하세요.
- **설계상 동작(테스트로 확인):** 11/8 이후에는 Open-Meteo를 더 이상 갱신하지 않습니다. 키가 없거나 AccuWeather가 실패하면 마지막 Open-Meteo 캐시를 `stale`로 표시해 보여 주며, 이 데이터는 시간이 지날수록 오래됩니다.

### P1 — 최신 소스의 운영 배포

- 앱 기능 기준 소스 `98e48cdb429710b871628047d80a1ec24f0717e4`에는 `ChatGPT 직접 열기` 안내가 포함돼 있습니다. 이후 handoff 문서와 CI 커밋도 `main`에 올라갔습니다.
- 운영은 v18, `c95e50858be0e5fb231872b57aea038968ec1a0b` 기준입니다. 최신 소스는 아직 운영에 반영되지 않았습니다.
- 2026-10-27 Claude Code 세션은 OpenAI Sites 커넥터·프로젝트 권한이 없어 배포하지 못했습니다. 소유권·`custom` 접근 정책·D1/R2 바인딩·비밀 존재 여부·익명 401도 직접 확인하지 못했습니다(운영 URL도 저장소에 없음). v18 상태는 이전 기록 기준이며 재확인되지 않았습니다. 이 세션의 변경은 테스트·CI·문서뿐이라 앱 런타임 동작은 바뀌지 않았습니다.
- 기존 Sites 프로젝트에 권한이 있는 개발자가 보안·모바일 점검 후 같은 비공개 접근 정책을 유지해 배포해야 합니다.

### P1 — 실제 기기/두 계정 회귀 테스트

- 허용된 두 계정으로 별도 세션에서 아이디어 투표, 일정 대기목록, 최종 일정 선택, 예산·체크리스트 동기화를 다시 확인합니다.

- iOS 공유 시트에서 ChatGPT가 앱 목록에 나타나는 것은 웹사이트가 보장할 수 없습니다. 현재 구현은 저장·프롬프트 복사·ChatGPT 열기 후 수동 첨부 대체 흐름입니다.
- 실제 iPhone과 실제 두 허용 계정은 이 개발 환경에서 검증되지 않았습니다(2026-10-27 Claude Code 세션 포함). 접근 허용 목록을 약화해 테스트하지 않습니다.

## 코드 품질

- 현재 `npm run lint`는 20 errors, 8 warnings로 실패합니다. 확인된 범위에는 API 라우트의 `any`, React hook ref/state effect 규칙, 이미지 요소 경고가 포함됩니다.
- 전체 lint를 한 번에 끄거나 무시하지 말고, 새 변경과 기존 문제를 나눠 우선순위를 정합니다. 현재 GitHub Actions는 타입 검사·상태 테스트·빌드를 실행합니다.
- 2026-10-27 기준 lint 재확인: 20 errors, 8 warnings로 기준과 동일하며 새 오류는 없습니다(새 `tests/` 파일은 lint 통과).
- 추적된 자동화 테스트는 아이디어 상태 테스트 4개(`npm run test:state`)와 날씨 서비스 테스트 10개(`npm run test:weather`, CI 포함)입니다. 날씨 테스트는 실제 `drizzle/` 마이그레이션을 `node:sqlite`에 적용한 가짜 D1과 가짜 fetch로 11/8 Taipei 자정 전환, 11/18~22 예보 범위, 16일 Open-Meteo 경계, 키 누락, 캐시 재사용, 503 재시도·백오프, 401 무재시도, 잘못된 응답 거부, 로그·URL의 키 미노출을 검증합니다. 실제 AccuWeather 호출은 하지 않습니다.
- 남은 테스트 공백: API 라우트(`requireAllowedMember`, same-origin 검사), 사진 업로드/삭제 API, 상태 동기화 API는 자동 테스트가 없습니다.

## 알려진 제품/플랫폼 제약

- 일반 iPhone 웹사이트는 백그라운드 지오펜스 알림을 안정적으로 보장하지 못합니다. 현재는 사용자가 사이트를 열고 위치를 허용한 동안의 근접 알림과 수동 체크인만 지원합니다.
- Higgsfield는 직접 API/세션 연결이 없습니다. 사진 선택→공유/저장→외부 편집→결과 재선택의 수동 흐름이며, 이미지 문구나 스타일의 정확도는 외부 생성기에 달려 있습니다.
- 저장 게이지의 10GB는 실제 R2 한도가 아니라 비교용 계획 수치입니다. 관리형 R2의 실제 용량/요금은 별도로 확인되지 않았습니다.
- 로그인이나 D1/R2 운영 바인딩이 없는 별도 호스팅에 소스만 복사해도 공동 기능은 운영되지 않습니다. 별도 배포는 인증·저장소 이전이 필요한 마이그레이션입니다.
- 독립 Cloudflare 스테이징 배포용 Access 인증 어댑터와 배포 스크립트가 추가됐습니다([STANDALONE_DEPLOYMENT.md](STANDALONE_DEPLOYMENT.md)). 2026-10-27 기준 Cloudflare 계정이 없어 실제 배포는 하지 않았습니다.
