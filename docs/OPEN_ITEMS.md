## 코드 품질

- 현재 `npm run lint`는 20 errors, 8 warnings로 실패합니다. 확인된 범위에는 API 라우트의 `any`, React hook ref/state effect 규칙, 이미지 요소 경고가 포함됩니다.
- 전체 lint를 한 번에 끄거나 무시하지 말고, 새 변경과 기존 문제를 나눠 우선순위를 정합니다. 현재 GitHub Actions는 타입 검사·상태 테스트·빌드를 실행합니다.
- 추적된 자동화 테스트는 아이디어 상태 테스트 4개입니다. 날씨 서비스는 과거 수동 검증 기록은 있으나 저장소의 독립 자동화 테스트 커버리지가 부족합니다. 전환 날짜·키 누락·캐시/실패·15일 전망 경계 테스트를 추가하는 것이 좋습니다.

## 알려진 제품/플랫폼 제약

- 일반 iPhone 웹사이트는 백그라운드 지오펜스 알림을 안정적으로 보장하지 못합니다. 현재는 사용자가 사이트를 열고 위치를 허용한 동안의 근접 알림과 수동 체크인만 지원합니다.
- Higgsfield는 직접 API/세션 연결이 없습니다. 사진 선택→공유/저장→외부 편집→결과 재선택의 수동 흐름이며, 이미지 문구나 스타일의 정확도는 외부 생성기에 달려 있습니다.
- 저장 게이지의 10GB는 실제 R2 한도가 아니라 비교용 계획 수치입니다. 관리형 R2의 실제 용량/요금은 별도로 확인되지 않았습니다.
- 로그인이나 D1/R2 운영 바인딩이 없는 별도 호스팅에 소스만 복사해도 공동 기능은 운영되지 않습니다. 별도 배포는 인증·저장소 이전이 필요한 마이그레이션입니다.
